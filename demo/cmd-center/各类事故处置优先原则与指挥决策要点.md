# 各类事故处置优先原则与指挥决策要点

**发布机构：** 上海市应急管理局  
**适用范围：** 上海市行政区域内各类突发事故应急处置  
**版本：** 2024年修订版

---

## 第一章 总则

### 1.1 核心原则

所有突发事故处置遵循以下优先原则（按优先级排序）：

1. **生命第一**：优先保障人员生命安全，救人重于救物
2. **控制扩大**：防止事态蔓延，控制次生灾害
3. **环境保护**：减少对周边环境和居民的影响
4. **财产保全**：在前三项条件满足后保护财产

---

## 第二章 建筑火灾处置优先原则

### 2.1 决策优先顺序

```
人员疏散 → 搜救被困者 → 控制蔓延 → 彻底扑灭 → 保护财产
```

### 2.2 疏散层级

| 优先级 | 疏散对象 | 操作要点 |
|--------|---------|---------|
| 1（最高）| 着火层及上下各一层居民/人员 | 立即疏散，不等确认 |
| 2 | 着火楼栋全部人员 | 根据火势发展启动 |
| 3 | 周边50m范围 | 火势超过3个楼层时启动 |
| 4 | 警戒圈内居民 | 大型高层火灾 |

### 2.3 关键决策树

**Q：楼道浓烟，人员是否内攻搜救？**
- 楼道温度 < 60℃ 且能见度 > 3m → **可内攻**
- 楼道温度 ≥ 60℃ 或大量浓烟 → **禁止内攻，改外攻+空中救援**

**Q：高层建筑，云梯车是否展开？**
- 火势在10层以上 → **必须**
- 楼栋高度超过52米且火点更高 → **申请高空平台车**

**Q：有人被困报告，是否升级响应？**
- 有人员被困（不论人数）→ **自动升Ⅲ级以上响应**

## 第三章 交通事故处置优先原则

### 3.1 决策优先顺序

```
现场安全防护 → 急救伤员 → 清障恢复交通 → 事故取证
```

### 3.2 封路范围决策标准

| 事故类型 | 最小封路范围 | 决策权 |
|---------|-----------|--------|
| 单车轻微碰撞 | 1条车道，30m | 交通协管员 |
| 多车追尾，有伤亡 | 2-3条车道，100m | 交警支队 |
| 大型车辆侧翻 | 封闭双向，200m | 区级交通管理局 |
| 危化品车辆事故 | 500m以上 | 市级指挥 |

### 3.3 "先急救后清障"原则

- 在伤员未全部救出和初步处置前，**禁止移动事故车辆**
- 危重伤员稳定（或医疗确认）后，方可启动清障
- 有危化品泄漏时，必须先完成洗消，再允许清障车辆进入

## 第四章 建筑坍塌处置优先原则

### 4.1 搜救时窗原则

| 时间段 | 幸存者存活率 | 指挥重点 |
|--------|-----------|--------|
| 0-6小时 | >70% | 最大化搜救人员投入 |
| 6-24小时 | 40-70% | 持续搜救，同步保障物资 |
| 24-72小时 | 10-40% | 搜救犬+声学探测 |
| >72小时 | <10% | 不放弃，但转入精细化搜索 |

### 4.2 重型机械使用禁令

**以下情况禁止使用挖掘机、推土机等重型机械：**
- 废墟内有生命迹象（声音/振动/热成像）
- 搜救犬尚未完成搜索
- 坍塌结构尚不稳定（可能引发二次塌落）

**允许使用重型机械的条件：**
- 专业搜救队确认区域无生命迹象
- 结构工程师评估坍塌体稳定
- 现场指挥官（支队级以上）签字确认

### 4.3 "黄金72小时"指挥决策

- **前24小时：** 全力投入生命搜救，所有其他任务让步
- **24-72小时：** 搜救与结构加固并行，防止继续塌陷
- **72小时后：** 转为"持续搜救+遇难者处置"双轨模式

## 第五章 洪涝灾害处置优先原则

### 5.1 转移路线决策规则

**优先规则：**
- **高地优先**：向地势高处转移，避免向低洼方向
- **地下禁入**：封闭地下通道、地下停车场入口
- **分批次转移**：老弱病残优先，避免人员拥堵踩踏

**禁止疏散路线（洪涝场景）：**
- 地下通道（有淹没风险）
- 地势低洼路段（积水深度 > 30cm 禁行）
- 临近水体的堤坝道路（溃堤风险）

### 5.2 抽水vs转移决策

| 情况 | 决策 |
|------|------|
| 积水深度 < 50cm 且水位稳定 | 就地抽水，配合交通管控 |
| 积水深度 50-150cm 或持续上升 | 低洼区居民转移 + 抽水同步 |
| 积水深度 > 150cm 或有溃堤风险 | 强制转移，暂停车辆通行 |

## 第六章 危化品泄漏处置优先原则

### 6.1 上风向集结原则

所有应急力量（消防、医疗、指挥）必须在事故点**上风向**集结：
- 上风向距离：≥500m（轻度泄漏）/ ≥1000m（重度泄漏）
- 禁止从下风向进入事故区域
- 现场指挥部设立于上风向

### 6.2 非专业人员禁入范围

| 泄漏类型 | 禁入半径 |
|---------|---------|
| 一般有机溶剂 | 200m |
| 液化气/LPG | 500m（含爆炸危险） |
| 氯气/氨气 | 800m |
| 高毒性物质（氰化物等） | 1000m以上 |

### 6.3 危化品事故"三不原则"

1. **不明物质不靠近**：未识别物质按最高危险级别处置
2. **无防护不进入**：没有对应防护装备，禁止任何人员进入
3. **不扑灭不收兵**：危化品火灾需确认完全扑灭，防止复燃

## 附录：事故处置决策速查

| 事故类型 | 第一优先 | 绝对禁止 | 升级条件 |
|---------|---------|---------|---------|
| 建筑火灾 | 疏散被困者 | 浓烟内攻 | 有人被困/多层蔓延 |
| 交通事故 | 急救伤员 | 未救人先清障 | 危化品/多人伤亡 |
| 建筑坍塌 | 声学探测生命 | 过早动重型机械 | 有生命迹象/大范围 |
| 洪涝 | 低洼区转移 | 走地下通道 | 溃堤风险/深水 |
| 危化品泄漏 | 上风向集结 | 无防护进入 | 爆炸风险/扩散超标 |
