# 指挥信息报告规范与决策日志

**发布机构：** 上海市应急管理局  
**适用范围：** 上海市突发事件应急处置指挥信息报告与记录  
**版本：** 2024年修订版

---

## 第一章 报告体系总览

### 1.1 报告类型

| 报告类型 | 时限要求 | 上报机构 | 触发条件 |
|---------|---------|---------|---------|
| 初报（电话） | 事件确认后**5分钟内** | 区级应急指挥中心 | 所有Ⅳ级以上事件 |
| 初报（书面） | 事件确认后**30分钟内** | 市应急管理局 | Ⅲ级以上 |
| 续报 | **每30分钟**一次 | 市政府应急办 | 重大及以上（Ⅱ级+） |
| 终报 | 事件处置完毕后**24小时内** | 市应急管理局 | 所有已上报事件 |

---

## 第二章 初报（首次报告）规范

### 2.1 初报必填内容

初报须包含以下**7要素**，缺少任一要素须在15分钟内补报：

1. **事件发生时间**（精确到分钟，如：14:23）
2. **事件发生地点**（精确到路口/门牌，如：世纪大道2000号×陆家嘴环路）
3. **事件类型**（建筑火灾/危化品泄漏/建筑坍塌/洪涝/交通事故/其他）
4. **初步规模评估**（着火面积/伤亡人数/影响范围）
5. **已知特殊风险**（是否有危化品/高压电/人员被困）
6. **已采取措施**（已到场力量/已启动响应级别）
7. **是否有人员伤亡**（精确数字或"待确认"）

### 2.2 初报模板（电话口头报告）

```
"[单位名称]向[上报机构]报告：
[时间]，[地点]发生[事件类型]。
初步判断[规模描述]，[伤亡情况]。
现场已部署[力量描述]，启动[响应级别]响应。
特殊情况：[有无危化品/被困人员/等]。
下一步联系人：[姓名/电话]。"
```

**示例：**
> "浦东应急指挥中心向市应急管理局值班室报告：14:23，世纪大道×陆家嘴环路路口某高层建筑25楼发生火灾。初步判断火势已蔓延至3个楼层，现场有人员被困报告。已调派FS1、FS2共7辆消防车到场，启动Ⅱ级响应。有浓烟蔓延。下一步联系人：张主任，手机138xxxx1234。"

## 第三章 研判报告规范

### 3.1 研判报告必含字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 事故类型 | 准确分类 | 高层建筑火灾 |
| 伤亡人数 | 精确数字或区间 | 重伤2人，轻伤5人，失联3人 |
| 波及范围 | 空间描述 | 着火楼栋半径200m范围 |
| 当前态势 | 动态描述 | 火势已控制，烟雾仍在扩散 |
| 已部署资源 | 各部门力量清单 | FF:7辆车/40人，ME:3辆救护车，TR:封路2处 |
| 环境风险 | 传感器数据 | CO 80ppm（超标），PM2.5 120μg/m³ |
| 下步行动 | 计划 | 申请跨区增援，启动居民疏散 |

### 3.2 研判报告发布频率

- **Ⅳ级事件**：初报后每60分钟一次
- **Ⅲ级事件**：初报后每30分钟一次
- **Ⅱ级及以上**：初报后每15分钟一次，重要进展即时发布

## 第四章 执行计划审批记录（HITL）

### 4.1 审批留痕要求

所有需要人工审批（HITL）的执行步骤，必须完整记录以下信息：

| 记录字段 | 内容 |
|---------|------|
| 步骤编号 | 如 step-003 |
| 步骤标题 | 简短描述 |
| 操作内容 | 具体执行动作 |
| 提交时间 | 精确到秒 |
| 审批人 | 姓名+职务 |
| 审批决定 | 批准/拒绝/修改后批准 |
| 审批时间 | 精确到秒 |
| 修改原因 | 如有修改，说明原因 |

### 4.2 HITL审批格式模板

```json
{
  "step_id": "step-003",
  "title": "调派FS1消防站4辆消防车至现场",
  "dept_code": "fire_brigade",
  "is_high_risk": true,
  "task": "立即调派陆家嘴消防站（FS1）全部可用消防车（4辆）前往世纪大道2000号火灾现场，预计3-5分钟到达，启动二楼云梯车部署",
  "submitted_at": "2025-03-15T14:25:33Z",
  "reviewer": "李大队长",
  "decision": "approved",
  "reviewed_at": "2025-03-15T14:25:58Z",
  "note": ""
}
```

### 4.3 高风险步骤审批时限

- **一般步骤**：审批人在60秒内未响应，系统提醒
- **高危步骤**（is_high_risk=true）：审批人在30秒内未响应，系统报警
- **紧急步骤**（生命风险）：设定超时自动执行，超时时间由现场指挥官设定（通常120秒）

## 第五章 终报（结案报告）规范

### 5.1 终报必含内容

1. **事件完整时间线**（接警→出动→到场→处置完毕）
2. **最终伤亡统计**（死亡/重伤/轻伤/失踪分类）
3. **财产损失估算**（房屋/设备/货物）
4. **各部门资源投入统计**（车辆/人员/物资）
5. **主要处置措施**（关键决策回顾）
6. **经验教训**（处置中的问题和改进建议）
7. **后续跟进事项**（环境恢复/建筑鉴定/保险理赔等）

### 5.2 终报时限

- 事件处置完毕后**24小时内**提交终报
- 特别重大事件（Ⅰ级）：可延长至48小时，但须提前说明
