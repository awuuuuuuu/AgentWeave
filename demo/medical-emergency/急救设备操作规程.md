# 天津市急救中心 急救设备操作规程

版本：V3.1 | 发布日期：2025-04-10 | 编制部门：装备保障科

## 1. AED 自动体外除颤仪

### 1.1 适用场景

用于院外心脏骤停（室颤或无脉性室速）患者，越早使用存活率越高：
- 1分钟内除颤：存活率约 90%
- 每延误1分钟：存活率下降 7-10%

### 1.2 操作步骤

1. **开机**：打开AED盖板，按下电源键（部分型号开盖自动开机）
2. **贴电极**：
   - 右侧电极：右锁骨下方（胸骨右缘）
   - 左侧电极：左腋中线第5肋间（乳头左侧）
   - 确保皮肤干燥，有毛发须剃除或用力按紧
3. **分析心律**：AED提示"正在分析，请勿触碰患者"，所有人离开
4. **除颤**：
   - 如提示"建议除颤"：大声告知"离开"，确认无人接触患者，按闪烁按钮放电
   - 如提示"不建议除颤"：立即继续CPR
5. **CPR与AED循环**：除颤后立即恢复CPR，2分钟后AED再次自动分析

### 1.3 注意事项

- 患者皮肤潮湿须擦干
- 安装起搏器者，电极避开起搏器位置至少 8 cm
- 不可用于 < 1岁婴儿；1-8岁儿童使用儿童专用衰减电极片
- 每次出车前检查AED电量和电极片有效期

## 2. 简易呼吸器（BVM）

### 2.1 组成

球囊、面罩、单向阀、氧气连接管、储氧袋

### 2.2 操作步骤（单人法）

1. 将患者头后仰，清除口腔异物，开放气道
2. 选择合适面罩（覆盖口鼻，不压眼球）
3. 左手 **EC手法** 固定面罩：
   - C形：拇指+食指紧压面罩
   - E形：其余三指抬下颌，保持气道开放
4. 右手每次均匀挤压球囊约 **1/2-2/3**（潮气量 500-600 mL）
5. 挤压时间约 **1秒**，观察胸廓起伏
6. 频率：成人 **10-12次/分**，儿童 **12-20次/分**

### 2.3 连接氧气

- 将储氧袋连接氧源，氧流量调至 **10-15 L/min**
- 连接氧气后吸入氧浓度可达 90% 以上
- 无氧源时球囊直接使用，吸入氧浓度约 21%

### 2.4 常见问题处理

| 问题 | 可能原因 | 处理方法 |
|------|---------|---------|
| 胸廓无起伏 | 面罩密封不严 / 气道未开放 | 重新调整 EC 手法和头位 |
| 通气阻力增大 | 气道异物 / 气管痉挛 | 检查并清除异物，考虑气管插管 |
| 胃部膨隆 | 通气量过大或速度过快 | 减少潮气量，适当降低频率 |

## 3. 心电监护仪

### 3.1 开机与导联连接

1. 按下电源键，等待自检完成（约10秒）
2. 连接5导联心电线：
   - RA（右臂）→ 右锁骨下
   - LA（左臂）→ 左锁骨下
   - RL（右腿）→ 右下腹
   - LL（左腿）→ 左下腹
   - V（胸导）→ 第4肋间胸骨左缘
3. 连接SpO₂探头于指端，确保指甲朝上
4. 缠绕无创血压袖带于上臂（肘窝上2cm）

### 3.2 参数设置与报警阈值

| 参数 | 正常范围 | 建议报警阈值（院前） |
|------|---------|------------------|
| 心率 | 60-100次/分 | 低于50 / 高于130 |
| SpO₂ | 95-100% | 低于90% |
| 收缩压 | 90-140 mmHg | 低于80 / 高于180 |
| 呼吸频率 | 12-20次/分 | 低于8 / 高于30 |

### 3.3 常见心律识别要点

- **室颤**：波形不规则、无明显QRS波，需立即除颤
- **室速**：宽QRS、频率>100次/分，有脉则药物复律，无脉则除颤
- **三度房室传导阻滞**：P波与QRS完全无关，须立即准备临时起搏
- **心脏停搏（Asystole）**：等电位线，继续CPR，考虑可逆原因（4H4T）

## 4. 设备维护与保养

### 4.1 日常检查（每班次）

- [ ] AED 开机自检通过，电量 > 80%，电极片在效期内
- [ ] 呼吸器球囊无破损，面罩密封圈完好，单向阀开闭正常
- [ ] 监护仪电量充足（>50%），导联线完整无断裂
- [ ] 吸痰机吸引压力正常（-40 ~ -80 kPa）
- [ ] 供氧系统：氧气瓶压力 > 10 MPa，连接件无漏气

### 4.2 故障报修

设备发现故障须立即贴"停用"标签，填写《设备故障报告单》提交装备科，禁止带故障设备出车。重要设备故障须同时口头告知班组长备用替换。
