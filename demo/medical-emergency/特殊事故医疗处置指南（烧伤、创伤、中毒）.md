# 特殊事故医疗处置指南（烧伤/创伤/中毒）

**发布机构：** 上海市急救医疗服务中心  
**适用范围：** 上海市各类特殊事故现场医疗处置规范  
**版本：** 2024年修订版

---

## 第一章 烧伤处置

### 1.1 烧伤面积估算（九分法）

| 身体部位 | 面积（%） |
|---------|---------|
| 头部+颈部 | 9% |
| 双上肢（各9%） | 18% |
| 躯干（前9+后9） | 18%（前后共36%含会阴1%） |
| 双下肢（各18%） | 36% |
| 会阴部 | 1% |

**儿童特殊：** 头部每岁减1%，双下肢每岁加1%（12岁后同成人）

### 1.2 液体复苏（Parkland 公式）

**适用于：** 烧伤面积 > 20%（Ⅱ度以上），需要静脉补液

**公式：** 24小时补液量 = 4mL × 体重（kg） × 烧伤面积（%）

| 补液分配 |
|---------|
| 前8小时补入总量的**一半** |
| 后16小时补入另一半 |
| 补液类型：乳酸林格液（前24小时首选）|

**示例：** 70kg患者，30%烧伤面积 → 24小时总量 = 4×70×30 = 8400mL  
前8小时补4200mL，后16小时补4200mL

### 1.3 转至烧伤专科条件

以下情况**必须**转至上海烧伤专科中心（东方医院烧伤科）：
- 烧伤面积 > 25%（成人）/ > 20%（儿童/老人）
- Ⅲ度烧伤面积 > 5%
- 面部/手部/会阴部深度烧伤（影响功能/外观）
- 确诊吸入性损伤（需气管插管+高压氧）
- 化学烧伤（需专业洗消）
- 合并电击伤

## 第二章 创伤处置

### 2.1 多发伤 ABCDE 评估

| 步骤 | 内容 | 关键操作 |
|------|------|---------|
| **A**（气道） | Airway | 检查气道通畅性，清除异物，下颌前推 |
| **B**（呼吸） | Breathing | 呼吸频率、氧饱和度、胸部起伏对称性 |
| **C**（循环） | Circulation | 出血控制、血压、脉搏、毛细血管充盈 |
| **D**（功能） | Disability | GCS评分（意识状态），瞳孔 |
| **E**（暴露） | Exposure | 脱去衣物全面检查，防止低体温 |

### 2.2 止血带使用时限

| 情况 | 操作 |
|------|------|
| 四肢大出血 | 伤口近心端5-8cm处扎止血带 |
| 材料 | 充气式止血带（首选）/ 布条（≥5cm宽，禁用铁丝/绳索） |
| 压力 | 上肢250mmHg / 下肢300mmHg，或刚好止血为准 |
| 最长时限 | **60分钟**（每60分钟松开5分钟让血液灌注，再重扎） |
| 记录 | 必须记录扎止血带时间（写在皮肤上或标签上） |

**超时风险：** > 6小时可能导致不可逆肢体损伤（须截肢）

### 2.3 开放性骨折处理

1. 不可将骨折端强行推回皮下
2. 用无菌/清洁纱布覆盖伤口（隔离细菌）
3. 夹板固定（固定上下各一个关节）
4. 禁止冲洗伤口（可能将细菌推入深层）
5. 在30分钟内送医（黄金时间窗）

## 第三章 中毒处置

### 3.1 CO中毒

**中毒程度与症状：**

| CO浓度 | 症状 | 处置 |
|--------|------|------|
| 50-100ppm | 头痛、轻度恶心 | 立即撤离，新鲜空气 |
| 100-400ppm | 头痛剧烈、视力模糊 | 撤离+100%高流量O₂ |
| 400-1000ppm | 意识障碍、心律失常 | 撤离+气管插管+高压氧 |
| >1000ppm | 昏迷、心跳停止 | CPR+高压氧（如能转运） |

**高压氧舱启动条件：**
- 意识障碍（任何程度）
- 心律失常
- 血COHb > 25%
- 孕妇（COHb > 15%）
- 儿童（COHb > 20%）

**上海浦东高压氧：** 东方医院设有高压氧舱

### 3.2 化学品皮肤/吸入中毒（洗消流程）

**皮肤污染：**
1. 立即在**洗消站**大量流水冲洗（≥20分钟）
2. 同时去除所有衣物（按医疗废物处理）
3. 不可用毛巾擦拭（会加速吸收）
4. 确认洗消充分后，医疗评估

**眼部污染：**
1. 立即流水冲洗（≥15分钟，不可闭眼）
2. 使用洗眼器或直接用干净流水
3. 不可使用眼药水或尝试中和（可能加重损伤）
4. 冲洗后立即眼科会诊

**吸入中毒（无特效解毒剂）：**
1. 撤离污染区（上风向）
2. 高流量吸氧
3. 观察呼吸功能（吸入性肺损伤可能延迟6-24小时出现）

## 第四章 特殊并发症

### 4.1 挤压综合征

**发生机制：** 建筑坍塌受压肢体恢复血流后，坏死肌肉释放肌红蛋白→肾衰竭

**高风险因素：**
- 单侧/双侧肢体受压 > 4小时
- 受压面积大（躯干受压更危险）

**预防措施（提取前开始）：**
1. 建立静脉通路，速度1-2L/小时
2. 碱化尿液（NaHCO₃静注）
3. 提取后密切监测尿量和尿色（正常：>0.5mL/kg/h，尿色浅黄）
4. 尿液变红/棕色→立即增加补液量，通知肾科

### 4.2 心理创伤

**大型事故（死亡≥5人）必须启动心理援助：**
- 现场：危机干预团队（≥2名心理咨询师）
- 对象：幸存者、目击者、遇难者家属、救援人员
- 方式：积极倾听、稳定情绪、信息提供
- 排除自杀/自伤风险

## 附录：特殊事故处置速查

| 情况 | 关键处置 |
|------|---------|
| 烧伤>20% | Parkland公式补液，转烧伤专科 |
| CO昏迷 | 撤离+插管+高压氧 |
| 止血带>60分钟 | 松5分钟→重扎，记录时间 |
| 挤压>4小时 | 提取前建立静脉通路 |
| 皮肤化学污染 | 流水冲洗≥20分钟，不可擦拭 |
| 骨折端外露 | 覆盖固定，30分钟内送医 |
