# 天津市急救中心 急救响应流程规范

版本：V2.3 | 发布日期：2025-03-01 | 编制部门：医疗质控科

---

## 1. 接警与调度流程

### 1.1 接警要求

- 调度员须在电话响铃 **3声以内** 接听，禁止超过5声未接
- 接警时必须采集：呼救地址、患者症状、呼叫人联系方式、现场人数
- 对不清楚地址的呼叫，须主动询问附近标志性建筑、道路名称

### 1.2 出车响应时限

| 等级 | 适用情形 | 出车响应时间 |
|------|---------|------------|
| 一级（紧急） | 心脏骤停、严重创伤、急性中毒、产科急症 | ≤ 3 分钟 |
| 二级（急症） | 急性胸痛、脑卒中、骨折、高热惊厥 | ≤ 5 分钟 |
| 三级（普通） | 慢性病加重、非急性转运 | ≤ 10 分钟 |

> **目标**：市区到达现场时间 ≤ 12 分钟，郊区 ≤ 20 分钟。

### 1.3 多车联动

遇重大事故（伤亡3人以上），调度员须同时：
1. 派出首辆急救车
2. 通知备用车辆待命
3. 上报中心值班主任
4. 联系接诊医院预留急救通道

## 2. 现场评估与处置流程

### 2.1 ABCDE 初步评估法

到达现场后，急救人员须在 **60 秒内** 完成初步评估：

- **A（Airway）气道**：确认气道通畅，有无异物阻塞
- **B（Breathing）呼吸**：观察胸廓起伏，听诊双肺，计数呼吸频率
- **C（Circulation）循环**：触诊颈动脉或桡动脉搏动，观察皮肤颜色
- **D（Disability）神经功能**：AVPU评分（清醒/声音/疼痛/无反应）
- **E（Exposure）暴露**：解开衣物检查全身，注意保温

### 2.2 心脏骤停处置流程

1. 确认无意识、无呼吸（≤10秒判断）
2. 立即呼叫协助，取出AED
3. 开始高质量胸外按压：
   - 频率 **100-120次/分**
   - 深度 **5-6 cm**
   - 按压位置：胸骨下半段
   - 每30次按压配合2次人工呼吸
4. AED到位后立即开机，按语音提示操作
5. 持续复苏至自主循环恢复（ROSC）或转运至医院

### 2.3 急性脑卒中处置流程

1. FAST评估（面/臂/言语/时间）
2. 监测生命体征，建立静脉通路
3. 血糖检测（排除低血糖）
4. **禁止** 给予降压药（除非收缩压 > 220 mmHg）
5. 转运至具备溶栓条件的卒中中心，预计到院时间须提前通报

## 3. 转运规范

### 3.1 转运原则

- 就近原则：优先送往15分钟行程内的医院
- 就急原则：心梗/卒中患者优先送往具备介入/溶栓能力的医院
- 就意愿原则：非急危重症患者可尊重患者意愿

### 3.2 转运途中监护要求

- 每5分钟记录一次生命体征
- 危重患者全程心电监护
- 保持静脉通路通畅，备用急救药品随时可用

### 3.3 交接要求

- 到达医院前 **5分钟** 通过无线电预报患者情况
- 与接诊医护进行 SBAR 交接（情况/背景/评估/建议）
- 交接后在系统内录入出车记录，时间精确至分钟

## 4. 特殊情形处理

### 4.1 拒绝急救处理

患者或家属拒绝急救或转运时：
1. 向患者/家属充分告知风险
2. 请其签署《拒绝急救知情同意书》
3. 如拒绝签字，须至少有2名急救人员见证并记录
4. 上报调度中心备案

### 4.2 途中死亡处理

如患者在转运途中死亡：
1. 立即停止复苏（由急救医师宣布）
2. 联系就近医院或公安机关
3. 保存现场记录，不得擅自移动遗体
4. 通知家属，做好情绪安抚
