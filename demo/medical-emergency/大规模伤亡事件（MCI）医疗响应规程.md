# 大规模伤亡事件（MCI）医疗响应规程

**发布机构：** 上海市卫生健康委员会急救医疗中心  
**适用范围：** 上海市大规模伤亡事件（Mass Casualty Incident）医疗响应  
**版本：** 2024年修订版

---

## 第一章 MCI 定义与分级

### 1.1 MCI 触发条件

**大规模伤亡事件（MCI）：** 伤亡人数超过当地医疗系统即时处置能力，需要启动特殊应急程序的事件。

| 级别 | 伤亡人数 | 启动响应 | 指挥层级 |
|------|---------|---------|---------|
| MCI-1（小规模） | 10-30人 | 区级医疗应急 | 浦东新区卫健委 |
| MCI-2（中规模） | 30-100人 | 市级医疗协调 | 上海市卫健委 |
| MCI-3（大规模） | > 100人 | 跨省医疗支援 | 国家卫健委协调 |

### 1.2 与普通急救的区别

| 普通急救 | MCI响应 |
|---------|---------|
| 全力救治每个患者 | 最大化群体生存率（可能放弃极危患者） |
| 所有患者送最近医院 | 按能力分流至对口医院 |
| 医疗资源充足 | 资源稀缺，需要分配优先级 |
| 标准急救程序 | 简化现场处置，快速后送 |

## 第二章 METHANE 报告格式

首次到达MCI现场的医疗指挥官，必须在**5分钟内**用METHANE格式向指挥中心报告：

| 字母 | 含义 | 示例 |
|------|------|------|
| **M** | Major incident（重大事件确认） | "确认MCI，启动应急响应" |
| **E** | Exact location（精确地点） | "世纪大道2000号某大厦前" |
| **T** | Type of incident（事件类型） | "高层建筑火灾，25楼起火" |
| **H** | Hazards（危险） | "浓烟，有CO，可能有人员被困" |
| **A** | Access（进入方式） | "主出口在南侧，消防通道从东进" |
| **N** | Number of casualties（伤亡数量） | "约50人，重伤10人，轻伤40人" |
| **E** | Emergency services（已到场力量） | "消防7辆，医疗3辆，警察10人" |

## 第三章 野战急救站设立

### 3.1 选址标准

- **距事故现场：** 100-500m（安全区，不受火/烟/坍塌影响）
- **位置：** 上风向、地势平坦、可通车辆
- **面积：** 每50名伤员需约500㎡作业空间

### 3.2 区域划分

```
[事故现场] → [伤员提取区] → [检伤分类区] → [急救处置区] → [转运区]
```

| 区域 | 功能 | 人员配置 |
|------|------|---------|
| 检伤分类区 | START分类，贴颜色标签 | 1名急救医师+2名护士 |
| 红区（立即处置） | 重伤优先急救，维持生命体征 | 2名医师+4名护士 |
| 黄区（延迟处置） | 中等伤情，等待转运 | 1名医师+2名护士 |
| 绿区（轻伤） | 轻伤自救互救，等待转运 | 1名护士监管 |
| 黑区 | 死亡或无法救治者（放弃治疗） | 专人记录，家属隔离 |
| 转运区 | 救护车装载，分流医院 | 1名调度员 |

## 第四章 伤员分流路线

### 4.1 上海浦东医院分流原则

**重伤（红标）→ 就近大型医院或专科医院**
- 烧伤：东方医院烧伤科（区内最强）
- 多发伤/骨折：第六人民医院东院（骨科专长）
- 危重综合：仁济医院南院（综合ICU强）

**中等伤（黄标）→ 区级综合医院**
- 浦东新区人民医院
- 张江医院

**轻伤（绿标）→ 社区卫生服务中心**
- 就近转移，减轻大医院压力

### 4.2 院间转运原则

- 单家医院ICU床位满载（达80%）时，启动院际分流
- 所有分流决定由医疗指挥官协调，记录在案
- 直升机转运适用：危重患者+距医院>20km，或道路拥堵

## 第五章 资源消耗速率估算

### 5.1 典型50人MCI消耗

| 物资 | 数量 | 更新频率 |
|------|------|---------|
| 静脉输液（1L袋） | 60-100袋 | 前2小时密集使用 |
| 绷带/止血敷料 | 100套 | 初期集中消耗 |
| 氧气瓶（10L） | 20-30个 | 持续消耗 |
| 血压计/血氧仪 | 10套 | 前4小时持续使用 |
| 手术手套（盒） | 50盒 | 全程消耗 |
| 颈椎固定器 | 30套 | 初期（提取阶段） |

### 5.2 血液需求估算

| 场景 | 血液需求 | 血库告警条件 |
|------|---------|------------|
| 10名重伤（创伤/烧伤） | A/O型各10-20单位 | 存量低于3日用量 |
| 30名以上 | 需向市血液中心紧急申请 | 立即启动献血动员 |
