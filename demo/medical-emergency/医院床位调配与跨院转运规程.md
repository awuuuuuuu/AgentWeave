## 第二章 满负荷触发条件与分流规则

### 2.1 医院满负荷判定标准

| 指标 | 触发二线分流阈值 |
|------|--------------|
| 急诊滞留患者数 | >50人（超出接诊区容量） |
| ICU 床位使用率 | >85% |
| 手术室等待时间 | >4小时（急症手术） |
| 救护车等候交接 | >15分钟 |

### 2.2 满负荷时的分流决策

**东方医院满负荷时备选：**
- 烧伤患者 → 浦东人民医院或跨区至长海医院（杨浦）
- 多发伤 → 仁济南院（外科能力强）
- 心血管急症 → 六院东（心内科强项）

**仁济南院满负荷时备选：**
- 普通急症 → 浦东人民医院
- 骨科创伤 → 六院东（浦东骨科最强）

### 2.3 跨区分流（浦东全区饱和）

| 分流方向 | 医院 | 跨区距离 | ETA |
|---------|------|---------|-----|
| 黄浦区 | 仁济医院西院 | ~6km（过隧道） | ~20分钟 |
| 杨浦区 | 长海医院 | ~8km | ~25分钟 |
| 徐汇区 | 瑞金医院 | ~12km | ~30分钟 |
| 闵行区 | 仁济医院南院 | ~15km | ~35分钟 |

## 第三章 危重患者转运适应症

### 3.1 适合转运的患者（需稳定）

- 气道已建立（气管插管/喉罩）
- 血压稳定（收缩压>90mmHg，无需大量血管活性药物）
- 出血已控制（活动性出血已临时处理）
- 骨折已固定（开放性骨折包扎）

### 3.2 暂不宜转运的患者

- 心肺复苏（CPR）进行中
- 严重颅内高压且无气道保护
- 大量活动性出血（出血点不明）
- 病情极不稳定，预计转运途中可能心跳停止

**原则：** 以上患者须在当前医院"就地稳定"后再决定转运。

## 第四章 直升机救援

### 4.1 启动条件

- 患者病情危重且道路转运时间>30分钟
- 道路拥堵导致救护车ETA超过正常2倍
- 特殊地形（海岛、偏远地区）无法陆路到达
- 大规模伤亡事件（MCI），救护车数量不足

### 4.2 浦东新区直升机停机坪

| 医院 | 停机坪位置 | 全天候使用 |
|------|----------|---------|
| 上海东方医院 | 楼顶（8层） | 是 |
| 仁济医院南院 | 地面停机坪 | 是 |
| 浦东国际机场 | 机场专用 | 是（需协调） |

**申请流程：** 120指挥中心 → 市急救中心 → 上海市航空医疗转运协调中心  
**响应时间：** 约20-30分钟（市内直升机）

## 第五章 批量转运时的救护车轮换调度

### 5.1 MCI场景救护车管理

**浦东新区可用救护车：** 8辆  
**周边可调配：** 浦西（黄浦/徐汇）约10辆，最快15分钟到位

### 5.2 轮换调度策略

| 轮次 | 操作 |
|------|------|
| 第1批（0-20分钟） | 最近待命车全部出动，送重伤患者至对口医院 |
| 第2批（20-40分钟） | 呼叫邻区增援，同时第1批出院返回 |
| 第3批（40分钟+） | 形成往复轮换，每批2-3辆连续转运 |

**车辆状态追踪：**
- 120调度系统实时显示：待命/前往现场/现场处置/转运中/回场
