# 检伤分类（Triage）标准与现场处置指南

**发布机构：** 上海市急救医疗服务中心  
**适用范围：** 上海市各类突发事故现场医疗检伤分类  
**版本：** 2024年修订版

---

## 第一章 START 检伤分类法

### 1.1 四色分类标准

| 颜色 | 分类 | 定义 | 处置优先级 |
|------|------|------|----------|
| **红色** | 立即处置（Immediate） | 危及生命，可治疗，立即急救 | 最高 |
| **黄色** | 延迟处置（Delayed） | 较重伤，暂无立即生命危险 | 中等 |
| **绿色** | 轻伤（Minor） | 轻伤或可自救，可步行 | 低 |
| **黑色** | 期待（Expectant/Dead） | 已死亡或极危无法救治 | — |

### 1.2 START 法操作步骤（30秒完成）

```
① 能步行 → 绿色，引导至绿区
② 不能步行 → 检查呼吸
   无呼吸 → 开放气道（仰头举颏）
     → 有呼吸：红色
     → 无呼吸：黑色
③ 有呼吸 → 检查呼吸频率
   > 30次/分或 < 6次/分：红色
   6-30次/分 → 检查循环
④ 循环：按压毛细血管，> 2秒恢复：红色
   ≤2秒恢复 → 检查意识
⑤ 意识：不能遵循命令：红色
   能遵循命令：黄色
```

## 第二章 不同事故类型的伤情特点

### 2.1 建筑坍塌（挤压伤）

**常见伤情：**
- 挤压伤（四肢/躯干长时间受压）
- 开放性骨折（碎片穿刺）
- 尘肺（大量粉尘吸入）
- 内脏损伤（腹腔挤压）

**特殊注意：**
- 受压超过4小时者：提取前建立静脉通路，防止"挤压综合征"（再灌注导致肾衰）
- 肢体挤压处可能有止血带效果；提取后立即检查血液循环

**检伤分类调整：**
- 建筑坍塌场景：看似轻伤的绿色患者，可能有内伤或迟发型休克
- 建议所有绿色患者在1小时内再评估一次

### 2.2 火灾（烧伤/吸入性损伤）

**常见伤情：**
- 体表烧伤（I/II/III度）
- 吸入性损伤（上下呼吸道灼伤）
- 一氧化碳中毒

**吸入性损伤判断（高度警惕！）：**
- 面部有烟灰、鼻毛焦黑
- 声音嘶哑、犬吠样咳嗽
- 口咽部充血肿胀

**CO中毒判断：**
- 头痛、恶心（CO 100-200ppm）
- 意识障碍（CO 400-800ppm）
- 昏迷/死亡（CO > 1000ppm）
- 皮肤可能呈樱桃红色（特征性表现，但敏感性差）

**烧伤分度快速判断：**

| 分度 | 外观 | 痛感 |
|------|------|------|
| I度（表皮） | 发红，无水泡 | 痛 |
| II度浅（真皮浅） | 水泡，基底红 | 非常痛 |
| II度深（真皮深） | 水泡，基底苍白 | 痛感减弱 |
| III度（全层） | 焦黑/灰白，皮革样 | 不痛（神经破坏） |

### 2.3 危化品泄漏（中毒）

**CO中毒处置：**
1. 立即移出污染区（上风向）
2. 高流量吸氧（15L/min面罩）
3. 昏迷患者：建立气道，送高压氧舱治疗
4. 血液碳氧血红蛋白（COHb）> 25%：立即高压氧

**有机磷农药中毒（SLUDGE症状）：**
- 唾液分泌过多、流涎
- 尿失禁
- 腹泻
- 胃肠痉挛
- 呕吐
- 处置：阿托品（解痉）+ 氯磷定（特效解毒）

**皮肤污染处置：**
- 立即在洗消站大量流水冲洗（≥20分钟）
- 去除所有衣物（按医疗废物处理）
- 眼部污染：流水冲洗≥15分钟

### 2.4 交通事故（多发伤）

**内脏损伤优先判断（隐蔽危险）：**
- 腹部压痛/腹肌紧张 → 怀疑腹腔脏器破裂（需手术）
- 骨盆骨折 → 大量内出血（可致失血性休克）
- 颈椎损伤 → 所有昏迷或颈痛患者均按颈椎损伤处理

**"铂金10分钟"关键操作：**
1. 气道开放（头颈中立位）
2. 颈椎固定
3. 大出血止血（直接压迫/止血带）
4. 静脉通路建立

## 第三章 黄金1小时原则

**"铂金10分钟"（到达现场后前10分钟）：**
- 评估场景安全性
- 完成START检伤分类
- 建立指挥架构
- 呼叫增援

**"黄金1小时"（到达后60分钟内）：**
- 所有红色患者开始转运
- 野战急救站建立运转
- 医院接收通知发出

**超过1小时的代价：**
- 失血性休克：未控制出血每分钟死亡风险增加5%
- 颅脑损伤：1小时内手术生存率>80%，3小时后降至<40%
