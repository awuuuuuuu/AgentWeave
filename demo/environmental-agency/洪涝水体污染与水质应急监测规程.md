# 洪涝水体污染与水质应急监测规程

**发布机构：** 上海市生态环境局  
**适用范围：** 上海市洪涝灾害引发的水体污染事件应急监测与处置  
**版本：** 2023年修订版

---

## 第一章 积水区污染物来源分析

### 1.1 洪涝积水污染物来源

| 来源类型 | 主要污染物 | 危害等级 |
|---------|---------|---------|
| 生活污水（下水道溢流） | 大肠杆菌、粪大肠菌群、氨氮 | 中等（传染病风险） |
| 工业废水（工厂泄漏） | 重金属、有机溶剂、酸碱 | 高（化学毒性） |
| 路面污染径流 | 石油、重金属（刹车粉尘）、农药 | 中等 |
| 医疗废水（医院地下室倒灌） | 药物、细菌、医疗废物 | 高（传染风险） |
| 农业径流（周边农田） | 农药、化肥、重金属 | 低-中 |

### 1.2 浦东新区洪涝高风险区域

- **惠南镇/新场镇南部**：地势低洼，易积水，附近有农业径流
- **金桥工业园区**：工厂集中，洪涝可能导致危化品泄漏进入积水
- **陆家嘴地下设施**：地下商场/停车场进水，可能有燃油/电池液污染

## 第二章 水体污染快速评估指标

### 2.1 现场快速检测（便携仪器）

| 指标 | 快速检测方法 | 告警阈值 | 含义 |
|------|-----------|---------|------|
| pH值 | pH试纸/便携pH计 | pH < 6或 > 9 | 强酸/强碱污染 |
| 溶解氧（DO） | 便携DO仪 | < 2mg/L | 严重有机污染 |
| 氨氮 | 比色管 | > 10mg/L | 污水溢流严重 |
| 浊度 | 浊度仪 | > 200NTU | 颗粒物/泥沙严重 |
| 石油类 | 荧光法仪 | > 0.3mg/L | 燃油/油脂污染 |
| 重金属（铅/镉） | X射线荧光（XRF）/比色管 | 依GB标准 | 工业污染 |

### 2.2 实验室检测指标（样品送检）

- **COD（化学需氧量）：** > 40mg/L 超标（III类水）
- **氨氮：** > 1.0mg/L 超标（地表水III类）
- **重金属（铅/镉/汞/铬）：** 依GB3838-2002 III类标准
- **大肠菌群：** > 10000个/L 存在卫生风险

## 第三章 应急水质监测采样

### 3.1 采样点布置

| 采样点位置 | 目的 |
|---------|------|
| 积水区上游（未受污染参考点） | 对照点，评估本底值 |
| 积水区中心区域 | 污染最严重区域 |
| 积水区排水出口处 | 监控污染物进入下游 |
| 附近河道（苏州河/黄浦江支流）入汇口 | 防止污染扩散 |
| 地下水监测井（若有） | 评估地下水污染 |

### 3.2 采样频率

| 事件等级 | 初始采样 | 后续频率 |
|---------|---------|---------|
| 一般洪涝（无工业区） | 积水开始后4小时 | 每12小时 |
| 工业区洪涝 | 积水开始后1小时 | 每4小时 |
| 危化品合并洪涝 | 立即 | 实时监测 |

## 第四章 污水溢出处置措施

### 4.1 防止进入地下管网

- 立即通知市排水公司关闭相关区域**截流阀**
- 在积水区域雨水口加设**活性炭吸附袋**（阻止有机物进入管网）
- 临时性堵塞下水口（沙袋/临时闸门）

### 4.2 现场处理

- **石油类污染：** 投放吸油毡、油脂吸附剂
- **强酸/强碱污染：** 撒生石灰（碱性积水）或硫代硫酸钠（酸性积水）中和
- **有机污染：** 投放粉末活性炭（5-10kg/1000m³积水）
- **细菌/传染病风险：** 在排水前加液氯或次氯酸钠消毒（余氯保持>0.5mg/L）

## 第五章 洪涝退水后环境恢复评估

### 5.1 退水后评估时序

```
退水后6小时 → 现场踏查（目测+快速检测）
退水后24小时 → 样品送实验室检测
退水后72小时 → 评估报告完成，确定是否恢复正常使用
退水后1周 → 土壤采样检测（评估地下渗漏影响）
```

### 5.2 场地恢复标准

| 区域类型 | 恢复条件 |
|---------|---------|
| 居民区 | 水质达III类，大肠菌群<10000个/L，无异味 |
| 工业区 | 依企业生产要求，通常需独立检测 |
| 农田 | 农业部门协同评估，重金属未超农田标准 |
| 儿童活动场所 | 额外检测铅/镉，pH 6.5-8.5，无化学残留 |

## 附录：洪涝水质响应速查

| 情况 | 措施 |
|------|------|
| pH < 5（强酸积水） | 投撒石灰，联系工业区排查泄漏源 |
| 石油膜（彩色油花） | 投放吸油毡，联系环保局取样 |
| 积水发黑发臭 | 污水溢流，禁止人员直接接触，通知排水部门 |
| 退水后草木枯死 | 可能有高浓度化学污染，申请专业检测 |
| 鱼类死亡（河道） | 严重污染，立即上报，采样检测 |
