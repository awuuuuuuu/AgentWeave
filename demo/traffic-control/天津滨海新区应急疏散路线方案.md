# 天津市滨海新区化工园区突发事故应急疏散路线方案

**文件编号：** BHXQ-JT-2025-007  
**编制机构：** 天津市滨海新区市政交通管控中心  
**协同编制：** 滨海新区应急管理局、滨海新区生态环境局  
**发布日期：** 2025年8月20日  
**版本：** 第二版

---

## 第一章 总则

### 1.1 编制目的

天津市滨海新区化工园区（以下简称"化工园区"）是全国重要的化工产业聚集区，发生危险化学品泄漏事故时，迅速有序地疏散周边居民和工作人员，是降低人员伤亡的关键措施。本方案针对化工园区大气污染突发事故场景，制定分级疏散路线、交通管制措施及信号灯应急方案，指导交通管控Agent实施应急管控。

### 1.2 地理概况

**化工园区核心区域：**
- 东至：渤海湾海岸线（约117.80°E）
- 西至：中央大道（约117.71°E）
- 南至：南海路（约39.00°N）
- 北至：北环路（约39.03°N）

**核心事故假设点：** XX合成氨有限公司，坐标 39.0231°N, 117.7432°E，位于港城大道388号，地处化工园区中心偏东位置。

**主导风向参考（天津冬春季）：** 西北风至东北风，全年平均风速3.5 m/s。

**疏散主方向：** 以冬春季典型东北风为例，扩散方向为西南偏南，疏散人员应向西北、正西方向转移。

## 第二章 路口编号与信号灯管控体系

化工园区及周边共设8个关键信号控制路口，编号S1至S8。各路口位置及初始状态如下：

| 编号 | 路口名称 | 坐标（纬度N, 经度E） | 距事故点距离 | 初始状态 |
|------|---------|-------------------|------------|---------|
| S1 | 化工路/港城大道 | 39.0241, 117.7389 | 约450m | 正常 |
| S2 | 化工路/中央大道 | 39.0198, 117.7201 | 约1450m | 正常 |
| S3 | 港城大道/滨海大道 | 39.0167, 117.7445 | 约750m | 正常 |
| S4 | 中央大道/南海路 | 39.0134, 117.7178 | 约1800m | 正常 |
| S5 | 滨海大道/塘沽桥 | 39.0089, 117.7512 | 约1550m | 正常 |
| S6 | 化工路/北环路 | 39.0289, 117.7367 | 约620m | 正常 |
| S7 | 北环路/中央大道 | 39.0301, 117.7189 | 约1780m | 正常 |
| S8 | 港城大道/南海路 | 39.0098, 117.7421 | 约1450m | 正常 |

**信号灯工作模式定义：**
- **正常模式**：按标准配时运行
- **应急绿波模式**：优先放行疏散方向车流，延长绿灯时间至90秒
- **单向清空模式**：仅允许疏散方向车辆通行，禁止逆向进入
- **全红封闭模式**：所有方向红灯，用于封闭危险区域路口
- **消防应急模式**：消防、救护车辆到达时自动切绿，其余方向保持红灯

## 第三章 分级疏散方案

### 3.1 Ⅳ级事故（一般，泄漏500m范围内）

**疏散对象：** 以事故点（S1路口附近）为圆心500米内全部人员，约 **850人**（含XX合成氨有限公司员工约320人，周边企业员工约530人）

**交通管制措施：**

| 路口 | 管制模式 | 说明 |
|------|---------|------|
| S1 | 全红封闭 | 禁止无关车辆进入500m隔离区 |
| S6 | 全红封闭 | 封闭北侧入口 |
| S3 | 消防应急模式 | 为消防救援车辆让行 |

**疏散路线：**
- 步行人员：沿化工路向西步行至S2（中央大道），再沿中央大道向北至北环路集合点
- 车辆疏散：化工路→中央大道（S2绿波）→北环路（S7放行）→集合点

**临时集合点：** 北环路/中央大道交叉口北侧停车场（约可容纳1500人）

### 3.2 Ⅲ级事故（较大，泄漏1000m范围内）

**疏散对象：** 以事故点为圆心1000米内全部人员，约 **3200人**

**交通管制措施：**

| 路口 | 管制模式 | 说明 |
|------|---------|------|
| S1 | 全红封闭 | |
| S3 | 全红封闭 | 封闭滨海大道东向入口 |
| S6 | 全红封闭 | |
| S8 | 全红封闭 | 封闭南侧港城大道 |
| S2 | 单向清空（西向） | 疏散通道，禁止东向进入 |
| S4 | 单向清空（西向） | 疏散通道 |
| S7 | 应急绿波（北向） | 疏散车流优先 |

**主疏散路线A（向西，主力路线）：**
化工路→S1（封闭/步行绕行）→化工路西段→S2（单向西行）→中央大道→S7（北向绿波）→北环路→疏散安置点（天津市滨海新区中医医院广场）

**主疏散路线B（向西南，备用）：**
港城大道→S8（封闭前）→南海路→S4（单向西行）→中央大道→大港方向→大港医院临时安置点

**临时集合点：**
- 主集合点：滨海新区中医医院广场（39.0312°N, 117.6891°E，容量约5000人）
- 备用集合点：北环路/中央大道停车场

### 3.3 Ⅱ级事故（重大，泄漏3000m范围内）

**疏散对象：** 以事故点为圆心3公里内全部人员，约 **18000人**（含化工园区工作人员约8000人，周边居民约10000人）

**交通管制措施：**

| 路口 | 管制模式 | 紧急调整说明 |
|------|---------|------------|
| S1 | 全红封闭 | 永久封闭至解除警报 |
| S2 | 单向清空 | 仅西向通行，禁止一切东向车辆 |
| S3 | 全红封闭 | 封闭海滨大道以东路段 |
| S4 | 单向清空 | 仅西向，每隔5分钟放行一批，防止拥堵 |
| S5 | 全红封闭 | 封闭滨海大道向东方向 |
| S6 | 全红封闭 | |
| S7 | 应急绿波（北向及西向） | 双向绿波，快速疏散 |
| S8 | 单向清空（南向大港方向） | 引导部分人员向南疏散 |

**主疏散路线（Ⅱ级三条并行）：**

**路线一（北向，主力）：** 化工路→中央大道（S2单向）→北环路→S7绿波北行→滨海新区中医医院广场集合，再转运至汉沽

**路线二（西向，辅助）：** 南海路→S4单向→中央大道→继续西行→塘沽城区安置

**路线三（南向，溢出）：** 港城大道→S8单向南→大港区→大港医院及周边安置点

**大规模人员步行疏散原则：**
- 沿道路右侧单向步行，禁止横穿马路
- 交警在S2、S4、S7路口驻守，人工引导
- 老弱病残人员优先安排公共交通（征用园区班车16辆）

### 3.4 Ⅰ级事故（特别重大，超3000m）

**额外措施：**
1. 联系天津市公安局交通管理局，申请启动高速公路应急分流（京津城际、沿海高速疏散滨海新区居民）
2. 联系地铁运营公司，延伸Z1线运营时间，增开疏散专列
3. 海河渡轮临时开行疏散路线
4. 向天津港请求帮助，在港区码头设置临时安置点

## 第四章 特殊情形处置

### 4.1 逆风向处置

若实际风向与预设东北风方向不同，按以下规则动态调整：

| 实际风向 | 下风方向 | 调整疏散主方向 | 优先开放路口 |
|---------|---------|-------------|-----------|
| 东北风（预设） | 西南 | 向西北疏散 | S2（西）、S7（北） |
| 东南风 | 西北 | 向东北疏散 | S6（北）、S7（北） |
| 西北风 | 东南 | 向西疏散困难，改向南 | S8（南）、S4（南） |
| 西南风 | 东北 | 向西南疏散，取道S4 | S4（西）、S2（西）|

### 4.2 夜间事故处置

- 所有疏散路线路口安排交警+警示灯引导
- 启用道路可变信息标志（VMS）显示"禁行/疏散方向"
- 广播车沿疏散路线循环播报
- 手机应急预警（WEA系统）向3公里范围内手机用户发送疏散通知

### 4.3 多事故点并发

若园区内出现多个泄漏点，优先疏散高浓度扩散区（ERPG-3范围），疏散路线与管制方案由应急指挥部实时调整，本方案中所有信号灯支持远程手动切换模式。

## 第五章 信号灯远程控制说明

### 5.1 控制权限

- **正常期**：信号灯由滨海新区市政交通管控中心统一管理
- **应急期**：应急指挥部授权后，交通管控Agent可接管远程控制权
- **控制粒度**：可单独控制每个路口的每个相位（每方向独立）

### 5.2 远程指令格式

交通管控Agent下发信号灯指令时，应包含以下要素：
- 目标路口编号（S1-S8）
- 切换模式（正常/应急绿波/单向清空/全红封闭/消防应急）
- 持续时间（分钟），或"持续至手动解除"
- 操作依据（引用本方案对应条款）

### 5.3 回滚机制

若信号灯指令引发严重拥堵，现场交警可通过手持终端一键回滚至正常模式，优先级高于远程指令。
