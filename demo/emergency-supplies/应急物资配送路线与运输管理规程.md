# 应急物资配送路线与运输管理规程

## 一、概述

本规程规定了浦东新区应急物资中心仓库至各主要事故区域的标准配送路线、车辆类型选择、应急通行权限及现场交接程序，确保物资在最短时间内到达事故现场。

**仓库出发坐标：北纬 31.2300°，东经 121.5100°（东方路123号）**

---

## 二、车辆类型与承载规格

### 2.1 车辆分类

| 车辆类型 | 载重 | 典型用途 | 响应速度 | 车辆数量（在库） |
|---------|------|---------|---------|---------------|
| 小型轻型厢式车（2 吨） | ≤2 t | 医疗耗材、通信设备、小批量个人防护 | 最快（市区通行灵活） | 6 辆 |
| 中型货车（5 吨） | ≤5 t | 综合物资、帐篷、担架、食品饮水 | 中等 | 4 辆 |
| 大型重型货车（10 吨） | ≤10 t | 沙袋、泵机、大型装备 | 较慢（部分道路受限） | 3 辆 |
| 冷链专用车 | ≤3 t（2–8℃） | 特种医疗试剂、冷链药品 | 中等 | 1 辆 |
| 危化品运输专用车 | ≤5 t | 消毒液、危化品洗消装置 | 专用路线（较慢） | 2 辆 |
| 应急指挥车 | 人员+设备 | 现场指挥官、通信设备快速前出 | 最快 | 2 辆 |

### 2.2 车辆调度优先级

1. 应急指挥车（先行侦察确认路线）
2. 小型轻型车（医疗急救、个人防护优先送达）
3. 中型货车（综合物资跟进）
4. 大型重型车（重型装备、大宗物资）
5. 专用车辆（冷链/危化品，按需调派）

## 四、标准配送路线

### 4.1 仓库至陆家嘴区域（路线 A）

```
东方路123号仓库
    → 东方路（向北）
    → 世纪大道（向西）
    → 张扬路立交
    → 陆家嘴环路
    → 事故现场
```

**备用路线：** 浦东南路 → 北大环路 → 陆家嘴

### 4.2 仓库至张江/金桥区域（路线 B）

```
东方路123号仓库
    → 龙阳路（向东）
    → 龙东大道（向东）
    → 张江路 / 金桥路 分叉
    → 事故现场
```

### 4.3 仓库至临港新片区（路线 C）

```
东方路123号仓库
    → 龙阳路 → 南六公路
    → S2 申嘉湖高速（南向）
    → S32 两港大道（东向）
    → 海港大道
    → 事故现场
```

**重要提示：** 前往临港途中须通过浦东收费站，应急车辆凭指挥中心授权码免费通行。

### 4.4 仓库至浦东国际机场（路线 D）

```
东方路123号仓库
    → 龙阳路
    → S2 申嘉湖高速（南向）
    → 机场大道（东向）
    → 机场货运区或旅客区
```

## 五、应急廊道通行权限

### 5.1 应急廊道启用条件

当事故达到 **Ⅲ级及以上**，或区应急管理局发布应急通行指令时，由**浦东新区公安交警支队**协调开放应急廊道，包括：

- 世纪大道（全线）快速路应急车道
- 龙东大道（全线）应急优先信号控制
- S2、S32 高速公路应急专用道
- 主要交叉路口人工疏导

### 5.2 应急通行证

应急物资车辆须持有以下之一方可使用应急廊道：

| 证件类型 | 颁发机构 | 有效期 |
|---------|---------|-------|
| 浦东新区应急管理局调拨函（纸质） | 区应急管理局 | 单次有效 |
| 市级应急通行证（电子） | 上海市应急管理局 | 事件有效期内 |
| 公安指挥中心临时授权码 | 区公安分局 | 48 小时 |

### 5.3 临时道路管制应对

| 情形 | 应对措施 |
|------|---------|
| 主干道封堵 | 切换备用路线，通知前方交警护送 |
| 高速封闭 | 改走地面国道（G318、G228等） |
| 洪涝积水道路 | 改用气垫船或等待水泵排水后通行 |
| 夜间施工占道 | 提前确认路况，联系施工方临时开道 |

## 六、夜间调拨授权程序

**夜间时段定义：晚 22:00 至次日 06:00**

```
①  现场人员或仓库值班员发现需求
          ↓
②  电话联系区应急管理局值班室（021-5800-XXXX）
          ↓
③  值班副局长（或授权值班长）口头授权并告知授权码
          ↓
④  仓库值班员核验授权码，记录于夜间调拨台账
          ↓
⑤  启动夜间配送（仓库 7×24 小时有备车）
          ↓
⑥  次日 08:00 前补办书面调拨申请单
```

**夜间配送注意事项：**
- 车辆须开启应急灯并悬挂"应急物资运输"标识
- 驾驶员须持有夜间行车补充培训证书
- 危化品类物资夜间配送须另行报备市危化品主管部门

## 七、现场交接与跟踪

### 7.1 到达现场流程

```
车辆到达现场指定卸货点
    ↓
与现场物资负责人核对《调拨清单》
    ↓
逐项清点数量、检查外观完整性
    ↓
双方签署《物资交接单》（一式三份：现场/仓库/指挥中心各一份）
    ↓
录入仓库管理系统（移动端 App 或纸质备案后补录）
    ↓
车辆返回或留守待命（由现场指挥官决定）
```

### 7.2 物资追踪

- **出库扫码：** 每件物资附条码，出库时扫码确认，实时同步至上海市应急物资保障平台。
- **在途跟踪：** 每辆车配备 GPS 设备，指挥中心可实时查看车辆位置及预计到达时间。
- **现场签收：** 签收数据同步至系统后，库存自动核减，触发低库存预警（如适用）。

### 7.3 物资返回/报废处理

| 情形 | 处理方式 |
|------|---------|
| 物资完好、未使用 | 返回仓库，重新入库（核验状态） |
| 物资使用后可复用（如担架、帐篷） | 清洁消毒后返库 |
| 医疗耗材（已拆封） | 现场处置，记录消耗量 |
| 危化品防护服（污染） | 按危废处理，不得返库，联系专业机构处置 |
| 损毁/遗失 | 填写《物资损毁/遗失申报表》，由使用单位承担责任 |
