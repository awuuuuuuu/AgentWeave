# 危化品事故防护物资使用规范

## 一、概述

本规范适用于浦东新区辖区内发生危险化学品泄漏、爆炸或火灾等事故时，应急救援人员的个人防护装备（PPE）选择、使用、检验和事后处置的全过程管理。正确使用防护物资是保护救援人员生命安全的第一道防线。

**物资来源仓库：东方路123号（31.2300°N, 121.5100°E）**

---

## 二、防护等级分类与适用场景

### 2.1 A 级防护（最高级别）

**适用场景：**
- 危化品种类未知、浓度极高的热区（污染核心区）
- 高度挥发性、剧毒或腐蚀性化学品（如氯气、氢氟酸、芥子气等）
- 皮肤/眼睛接触即可致命的环境

**标准配置：**

| 装备 | 规格要求 |
|------|---------|
| 全封闭防化服 | EN 943-1 气密型，内置 SCBA 安装空间 |
| 正压式空气呼吸器（SCBA） | 6.8L/30MPa，至少 30 分钟供气 |
| 内层手套 | 丁腈胶厚型 |
| 外层手套 | 丁基橡胶重型防化手套 |
| 防化靴 | 丁基橡胶，防砸防穿刺 |
| 密封胶带 | 用于接缝密封加固 |

**关键限制：**
- A 级防护服内温度极高，**每次作业时间不超过 30 分钟**（含穿脱）
- 必须双人进入热区，严禁单人作业
- 穿戴后须由另一名人员检查气密性

---

### 2.2 B 级防护

**适用场景：**
- 化学品种类已知、毒性较高但蒸气压较低
- 危化品浓度较低的温区（污染缓冲区）
- 需要高级别呼吸防护但皮肤接触风险相对较低

**标准配置：**

| 装备 | 规格要求 |
|------|---------|
| 连体式防溅防护服 | EN 14605 液体防溅型，非气密 |
| 正压式空气呼吸器（SCBA） | 6.8L/30MPa |
| 化学防护手套（重型） | 丁腈或丁基橡胶 |
| 防化靴 | — |
| 防护眼镜/面屏 | 配合防化服使用 |

**作业时间：** 受 SCBA 气瓶限制，**单次不超过 45 分钟**

---

### 2.3 C 级防护

**适用场景：**
- 化学品已知且浓度在可过滤范围内
- 冷区（安全隔离区外围）
- 洗消站工作人员、现场后勤保障人员

**标准配置：**

| 装备 | 规格要求 |
|------|---------|
| 连体防护服（Tyvek 或 PE 涂层） | 防液溅 |
| 全面型防毒面具 + 化学滤毒罐 | 按化学品类型选配滤罐 |
| 化学防护手套（轻型） | 丁腈 |
| 防化靴套或雨靴 | — |

**注意：** C 级防护**不提供**气密性保护，仅适用于已知、低浓度场景。

---

### 2.4 D 级防护（最低级别）

**适用场景：**
- 外围警戒区、媒体区
- 指挥所（距离热区 150 米以上）
- 无接触风险的后勤人员

**标准配置：**

| 装备 | 要求 |
|------|------|
| 工作服 | 长袖长裤 |
| 安全帽 | GA 44 标准 |
| 手套（普通型） | — |
| 护目镜（防飞溅） | 可选 |
| N95 口罩 | 如空气中有刺激性气味时必戴 |

## 三、SCBA 正压式空气呼吸器操作规程

### 3.1 穿戴步骤

```
① 检查气瓶压力（满瓶≥28MPa，低于20MPa禁止使用）
    ↓
② 检查面罩密封圈是否完好，镜片是否清晰
    ↓
③ 背负气瓶框架，调整肩带和腰带至舒适位置
    ↓
④ 打开气瓶阀门（顺时针拧松后反转），听到供气声
    ↓
⑤ 戴上面罩，拉紧头带（先拉两侧，再拉顶部）
    ↓
⑥ 用手掌盖住面罩进气口，深吸气，确认无漏气
    ↓
⑦ 连接供气软管，确认正压供气正常
    ↓
⑧ 由搭档从外部检查整体密封情况
    ↓
⑨ 确认无误后方可进入作业区域
```

### 3.2 使用时间限制

| 气瓶规格 | 额定时间 | 实际作业时间（含余量） | 低压报警压力 |
|---------|---------|-------------------|------------|
| 6.8L / 30MPa | 约 60 min | **≤45 min（正常强度）** | 5–6 MPa（约剩 10 min） |
| 6.8L / 30MPa | 约 60 min | **≤30 min（重体力劳动）** | 5–6 MPa |

**强制规定：**
- 听到低压报警（每分钟响 1 次）后，**立即撤离热区**，不得继续作业
- 每次作业后气瓶须送回充气，不得使用未满瓶气瓶进入热区
- 作业期间严禁摘下面罩

### 3.3 应急情况处理

| 情形 | 处置方式 |
|------|---------|
| 面罩意外脱落 | 立即屏气，双手捂住口鼻，快速撤离 |
| 气瓶漏气 | 关闭气瓶阀，立即撤离 |
| 面罩进雾（过热） | 降低呼吸频率，减缓动作，尽快撤离 |
| 人员晕倒 | 搭档立即拖拽至安全区域，不得单独离开 |

## 四、防化服完整性检查步骤

### 4.1 穿前检查（A 级气密型）

1. **外观检查：** 查看防化服表面有无裂缝、针孔、磨损、化学污渍痕迹
2. **拉链检查：** 拉链应运动顺畅，密封条（双层）无破损
3. **手套/靴套连接处：** 检查密封圈是否完好，无老化龟裂
4. **面窗：** 透明度良好，无划痕影响视线，密封圈无变形
5. **充气测试（A 级必做）：**
   - 将防化服内充气至轻微鼓胀状态
   - 静置 3 分钟，观察是否瘪气
   - 如有明显漏气，严禁使用，立即报废

### 4.2 穿后检查（由搭档完成）

| 检查部位 | 检查内容 |
|---------|---------|
| 拉链 | 是否拉到底并锁扣 |
| 手套接合处 | 是否用胶带密封 |
| 靴套接合处 | 是否用胶带密封 |
| SCBA 连接口 | 导管是否卡紧，无松动 |
| 整体 | 有无明显皱折或局部紧绷 |

## 五、洗消站设置规程

### 5.1 选址原则

- 设置在**事故源上风方向 150 米处**（使用手持风速仪确认风向）
- 与热区之间须有明确的隔离警戒带
- 地面坚硬（混凝土或沥青），便于收集洗消废水
- 周边 50 米内无居民、无饮用水源

### 5.2 洗消站布局

```
[热区方向] → [一洗区（粗洗）] → [二洗区（精洗）] → [脱装备区] → [人员洁净区] → [冷区]
```

| 分区 | 功能 | 设备配置 |
|------|------|---------|
| 一洗区（粗洗） | 去除大量污染物 | 高压水枪×2，洗消液（1%次氯酸钠） |
| 二洗区（精洗） | 去除残留污染物 | 低压淋浴装置，洗消液（0.5%次氯酸钠） |
| 脱装备区 | 有序脱下防护装备 | 封闭废物桶×4，辅助人员×2 |
| 人员洁净区 | 人员最终清洁 | 淋浴×2，毛巾，洁净更衣区 |

### 5.3 洗消废水处理

- 洗消废水须收集至**密封集液桶**，不得直接排入雨水沟或地表水
- 每次洗消后记录废水量，由专业危废公司处置
- 场地恢复后须由第三方检测机构采样确认无残留污染

## 六、污染装备处置规程

### 6.1 分类处置原则

| 装备类型 | 污染程度 | 处置方式 |
|---------|---------|---------|
| A 级防化服 | 接触剧毒/未知化学品 | **一律报废，按危险废物处置** |
| A 级防化服 | 接触低毒且经专业鉴定 | 由专业机构深度洗消后评估复用 |
| B/C 级防化服 | 任何化学品接触 | 洗消后评估；如有破损则直接报废 |
| 化学防护手套 | 任何接触 | 报废，按危废处置（不得随普通垃圾丢弃） |
| SCBA（外表面污染） | — | 洗消后继续使用，内部气路不受影响 |
| SCBA（内部污染） | 面罩内部接触化学品 | 气路部件报废，气瓶可复用（充气后检测） |

**严禁行为：**
- 将污染防化服装入普通垃圾袋后随意丢弃
- 将污染手套冲洗后继续使用
- 未洗消的 SCBA 面罩在下次救援中使用

### 6.2 报废申报

1. 填写《应急物资报废申请单》
2. 注明化学品名称、接触时长、污染程度
3. 交仓库管理员签收，联系危废公司上门收取
4. 同步通知仓库补充相应物资
