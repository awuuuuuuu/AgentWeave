# 消防车辆调派资源管理规范与跨区支援流程

**发布机构：** 上海市消防救援总队浦东支队  
**适用范围：** 浦东新区消防车辆调派与跨区协作  
**版本：** 2024年修订版

---

## 第一章 调派决策树

### 1.1 火情等级与出动车辆对照

```
接警 → 判定火情等级 → 查询可用车辆 → 下达调度令
```

| 火情等级 | 触发条件 | 首批出动 | 最少车辆数 |
|---------|---------|---------|---------|
| Ⅳ级（一般） | 小面积，无伤亡 | FS1：1-2辆 | 1辆 |
| Ⅲ级（较大） | 中等规模/有伤亡 | FS1+FS2：3-5辆 | 3辆 |
| Ⅱ级（重大） | 大规模/多人伤亡 | FS1+FS2+FS4：≥6辆 | 6辆 |
| Ⅰ级（特别重大） | 特大/跨区 | 全浦东+跨区：≥10辆 | 10辆 |

### 1.2 陆家嘴区域标准预案（世纪大道×陆家嘴环路）

**Ⅳ级：**  
首批：FS1出动2辆；FS2备勤

**Ⅲ级：**  
首批：FS1出动3辆，FS2出动2辆  
合计：5辆，约40人  
到场ETA：FS1约3-5分钟，FS2约10分钟

**Ⅱ级：**  
首批：FS1全出（4辆）+ FS2全出（3辆）  
增援：FS4出2辆，FS3出1辆  
总计：10辆，80人以上  
同步申请：黄浦、静安跨区增援

## 第二章 多站联动调派

### 2.1 主站+邻近站备援模式

- **主站**：距离最近、最先到场，承担初始进攻任务
- **备援站**：主站到达后5-10分钟内跟进，承担供水、轮换、外围任务
- **增援站**：Ⅱ级以上事故调集，承担长时间作战保障

### 2.2 调派优先级原则

1. **就近原则**：优先调集事故点5km以内的消防站
2. **能力匹配**：高层火灾必须包含有云梯车/高喷车的消防站
3. **预留原则**：任何情况下，辖区至少保留1辆水罐车待命
4. **动态调整**：随火势发展，现场指挥官可申请追加调派

## 第三章 消防车通行优先权

### 3.1 法律依据

根据《中华人民共和国消防法》第45条：

- 任何单位和个人不得阻拦消防车、消防艇执行消防救援任务
- 消防车在执行紧急任务时，可以超越交通信号限制
- 其他车辆和行人必须立即让行

### 3.2 与交通部门协作

消防调度员在下达调度令的同时，须通知交通指挥中心：

1. **救援走廊需求**：从消防站到事故点的路线，申请"消防应急绿波"
2. **警戒区封路**：事故点周边警戒圈内道路申请封闭
3. **路口绿波范围**：通常为消防站→事故点沿线路口，全程绿波放行

**联动格式（电话通报）：**
> "交通指挥中心，消防调度通报：FS1陆家嘴站正出动，前往世纪大道×陆家嘴环路，请开启陆家嘴环路全线绿波，预计3分钟到达。"

## 第四章 消防员轮换管理

### 4.1 高强度作业轮换周期

| 作业类型 | 最长连续作业时间 | 轮换后休息时间 |
|---------|---------------|-------------|
| 内攻灭火 | 20分钟（含撤退时间） | ≥20分钟 |
| 佩戴空气呼吸器作业 | 30分钟（气量消耗至50%） | ≥20分钟 |
| 高温环境作业（>40℃） | 15分钟 | ≥30分钟 |
| 重体力搬运 | 45分钟 | ≥15分钟 |
| 指挥协调 | 4小时 | 轮换指挥官 |

### 4.2 消防员状态监控

- 现场医疗急救人员负责监测轮换消防员状态
- 体温超过39℃、心率超过150bpm：强制休息
- 出现意识模糊/协调障碍：立即送医

## 第五章 市级特种增援申请

### 5.1 申请条件

向上海市消防救援总队申请特种增援的条件：
- 浦东辖区5个消防站全部出动，仍无法控制火势
- 需要特种装备（101米登高平台车、消防机器人）
- Ⅰ级特别重大事故
- 同时发生2起以上Ⅱ级事故

### 5.2 申请流程

```
浦东支队支队长 → 上海市消防救援总队值班室 → 总队指挥长批准 → 特勤大队出动
预计响应时间：总队批准后30-45分钟到达浦东
```

### 5.3 跨省互援（大型灾害）

- 启动条件：上海市级特种力量不足，或跨省大型灾害
- 申请路径：市消防救援总队 → 国家消防救援局 → 就近省份调配
- 到达时间：苏浙两省约2-3小时

## 第六章 灾后归队与器材维护

### 6.1 回撤优先级

1. 首先回撤跨区增援力量（外省市/跨区）
2. 其次回撤远距离浦东辖区（FS3、FS4、FS5）
3. 最后：FS1（最近站）留守警戒至移交公安

### 6.2 器材维护记录

归队后4小时内完成：
- 消防水带清洗晾干（不可折叠储存，防止老化）
- 空气呼吸器充气复检（确认满气量）
- 车辆水箱注满
- 受损器材登记上报，申请更换
- 出动记录归档（时间/地点/出动车辆/人员）
