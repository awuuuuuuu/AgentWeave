# 危化品火灾特殊处置指南

**发布机构：** 上海市消防救援总队  
**适用范围：** 上海市危险化学品火灾事故处置  
**版本：** 2024年修订版

---

## 第一章 危化品识别

### 1.1 危险标识体系

| 标识类型 | 用途 | 示例 |
|---------|------|------|
| UN编号 | 国际通用物质编号 | UN1203（汽油）、UN1017（氯气） |
| GHS菱形标识 | 危险类别图形符号 | 红色火焰（易燃）、骷髅（剧毒） |
| NFPA 704菱形 | 美标危险等级（0-4级） | 蓝（健康）/红（燃烧）/黄（反应） |
| 中国危化品标签 | 国标GB/T 16483 | 含应急处置指南编号 |

### 1.2 常见危化品燃烧特性

| 物质类别 | 燃烧特征 | 处置要点 |
|---------|---------|---------|
| 液化石油气（LPG） | 蓝色火焰，气体泄漏后爆炸 | 冷却容器，不可用水扑灭气体火焰 |
| 汽油/柴油 | 黄橙色火焰，流淌燃烧 | 泡沫覆盖，防止蔓延 |
| 乙醇/甲醇 | 淡蓝色火焰，肉眼难见 | 抗溶泡沫，严禁用普通干粉 |
| 有机溶剂（苯/甲苯） | 黑烟，毒性较高 | 泡沫+干粉，避免下风向 |
| 强氧化剂（硝酸盐） | 助燃，加剧其他物质燃烧 | 大量水冷却，隔离可燃物 |

## 第二章 禁止用水扑救的物质

以下物质与水反应可能产生爆炸、有毒气体或剧烈放热，**严禁用水扑救**：

| 物质 | 与水反应 | 替代灭火剂 |
|------|---------|---------|
| 碱金属（钠/钾/锂） | 产生氢气+爆炸 | 干砂/碳酸钠粉 |
| 电石（碳化钙） | 产生乙炔气 | 干砂/石墨粉 |
| 磷化铝 | 产生磷化氢（剧毒） | 干砂，禁止喷雾水 |
| 铝粉/镁粉 | 高温下与水爆炸 | 干砂/氯化钠粉 |
| 发烟硫酸 | 剧烈放热+飞溅腐蚀液体 | 干砂，远距离处置 |

**原则：** 处置未知危化品火灾时，优先使用干砂隔离，等待危化品专家到场确认。

## 第三章 不同灭火剂适用场景

| 灭火剂 | 适用场景 | 不适用场景 |
|--------|---------|----------|
| 泡沫（AFFF） | 烃类液体（汽油/柴油）火灾 | 极性溶剂（醇类）、水反应物质 |
| 抗溶泡沫 | 醇类、酯类、酮类溶剂火灾 | 烃类（效率较低） |
| 干粉（ABC） | 气体/液体/固体火灾 | 精密设备（污染严重） |
| CO₂ | 电气设备、精密仪器 | 金属火灾、大空间（效果差） |
| 惰性气体（氮气/氩气） | 特殊工业场景 | 不适用于野外开放区域 |
| 水雾 | 降温冷却、驱散烟雾 | 禁水物质火灾 |
| 干砂 | 金属火灾、小范围禁水物质 | 大面积火灾（覆盖量不足） |

## 第四章 爆炸风险评估

### 4.1 BLEVE（沸腾液体膨胀蒸气爆炸）

**危险场景：** 密闭容器（液化气罐/储油罐）受外部火源加热时

**BLEVE 前兆信号（立即撤离！）：**
- 容器外壳出现局部红热区域
- 安全阀连续鸣叫（压力急剧升高）
- 容器附近火焰颜色变化（通常伴随金属氧化）
- 容器发出低沉"嗡嗡"声

**安全距离：**
| 容器容量 | 最小安全距离 |
|---------|------------|
| < 100kg LPG | 200m |
| 100-500kg LPG | 500m |
| > 500kg LPG（槽罐车） | 1000m |

### 4.2 蒸气云爆炸（VCE）

- 大量可燃气体/蒸气泄漏后遇点火源
- 危险距离：泄漏量的1/100体积半径（约100-500m）
- **预防措施：** 隔离点火源（切断电源、禁止使用明火工具）

## 第五章 消防员撤离信号与安全管理

### 5.1 撤离信号

| 信号方式 | 含义 |
|---------|------|
| 警笛长鸣3次 | 立即撤离（危险爆炸风险） |
| 警笛短鸣5次 | 有序撤退（任务完成/轮换） |
| 无线电广播"撤退" | 区域撤离 |
| 发光信号弹（红色） | 紧急全体撤离 |

### 5.2 危化品现场人员管理

- **个人防护：** 危化品火灾必须穿戴A级或B级化学防护服+SCBA
- **双人原则：** 任何进入危险区的消防员，必须2人同行
- **安全员制度：** 现场必须有专人监控人员状态，记录进出时间

### 5.3 洗消程序

消防员撤出危化品区域后：
1. 在热区/温区边界进行初步洗消（大量清水冲洗）
2. 进入洗消站进行彻底洗消（专业洗消液）
3. 丢弃受污染的一次性防护装备
4. 医疗监测（至少30分钟）
