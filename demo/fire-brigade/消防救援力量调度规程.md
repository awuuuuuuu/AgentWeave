# 消防救援力量调度规程

**发布机构：** 上海市消防救援总队浦东支队  
**适用范围：** 上海市浦东新区消防救援力量调度  
**版本：** 2024年修订版

---

## 第一章 调度原则

### 1.1 基本原则

1. **就近优先**：优先调集事故点最近的消防站力量
2. **分级响应**：按事故等级调集对应力量
3. **动态跟踪**：实时掌握各消防站车辆和人员状态
4. **预留后备**：任何情况下辖区至少保留1辆水罐车待命

### 1.2 响应等级

| 等级 | 触发条件 | 调集规模 | 指挥层级 |
|-----|---------|---------|---------|
| Ⅳ级（一般） | 小面积火灾，无伤亡 | 1-2辆，8-16人 | 中队长 |
| Ⅲ级（较大） | 中等规模，有伤亡或被困 | 3-5辆，24-40人 | 支队长 |
| Ⅱ级（重大） | 大规模火灾，多人伤亡 | 6-10辆，50-80人 | 支队长+总队协调 |
| Ⅰ级（特别重大） | 特大灾害，跨区域 | 10辆以上，100人以上 | 总队指挥 |

## 第三章 调度流程

### 3.1 标准调度流程

```
接警 → 判断等级 → 确定最近可用消防站 → 下达调度令
  → 消防站出动（3分钟内） → 到达现场（5km/7分钟）
  → 现场指挥官评估 → 请求增援（如需）
```

### 3.2 调度决策要素

下达调度令前，调度员须确认：
1. **事故地点精确坐标**（不得仅凭地名）
2. **事故类型**（建筑火灾/危化品/人员被困）
3. **就近消防站可用车辆数**（调度系统实时显示）
4. **道路畅通情况**（高峰期路线备选）

### 3.3 世纪大道×陆家嘴环路区域预案

针对浦东新区核心区（世纪大道、陆家嘴、浦东南路沿线）发生火灾的标准调度方案：

**Ⅳ级（小火）：**
- 首批：FS1（陆家嘴站）出动2辆，FS2（世纪公园站）备勤

**Ⅲ级（较大火灾，如建筑多层蔓延）：**
- 首批：FS1出动3辆，FS2出动2辆
- 到场时间：FS1约3-5分钟，FS2约10分钟
- 合计：5辆消防车，约40人

**Ⅱ级（重大火灾，多层蔓延+伤亡）：**
- 首批：FS1全部出动（4辆），FS2全部出动（3辆）
- 增援：FS4（金桥站）出动2辆，FS3（张江站）出动1辆
- 总计：不少于10辆，80人以上
- 同步申请：临近黄浦、静安区跨区增援

## 第四章 回撤与归建

### 4.1 回撤条件

经现场指挥官确认后，可申请回撤：
1. 明火已完全扑灭，无复燃风险
2. 现场已移交给公安封控
3. 伤亡处置完毕，医疗急救已接手

### 4.2 回撤优先级

先撤离**支援力量**（外区调集的车辆），后撤离**辖区力量**：
1. 首先：跨区增援消防站车辆归建
2. 其次：远距离浦东辖区（FS3、FS4、FS5）车辆归建
3. 最后：事发地最近站（FS1）留守现场警戒直至移交
